TRANSPORT SECURITY

WHAT IS HSTS?

HTTP Strict Transport Security is an HTTPS response header that tells a browser to use HTTPS only for a domain during a defined period. It helps prevent protocol-downgrade and cookie exposure caused by an initial HTTP request. HSTS is effective only after the browser receives it over a valid HTTPS connection; includeSubDomains extends the rule to subdomains.
