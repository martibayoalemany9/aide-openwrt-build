THE OBJECTIVE

A small binary for a constrained router.

The router package feeds did not provide AIDE. We reproduced the device environment in QEMU, assembled the compiler in tmpfs, built mandatory cryptographic dependencies statically, and kept only musl and libgcc as runtime dependencies.

INTEGRITY DATABASE

What it is

An AIDE inventory of permissions, ownership, size, timestamps, type, link count, and SHA-256 content digests. It is not SQL.

Where it lives

/etc/aide/aide.db

The persistent policy is /etc/aide.conf; the executable is /usr/bin/aide. OpenWrt's /var is volatile.

How to check

aide --config=/etc/aide.conf --check

Exit 0 is clean. Added, removed, and changed files set bit flags 1, 2, and 4.

Trust rule

Keep read-only, off-router copies of both the database and policy. A baseline controlled by the monitored host alone cannot prove that host is trustworthy after compromise.

ACTIVE /etc/aide.conf

Persistent baseline. Quiet where the router is expected to write.

The AIDE database and dynamic GL.iNet service databases are excluded. All core executable, library, configuration, web, and root paths are covered.
